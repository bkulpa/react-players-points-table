# React Players Points Table

Educational React application that displays player scores and calculates summary statistics.

## Technologies

- React
- JavaScript / TypeScript tooling
- Fetch API
- CSS

## Features

- Loads player data from a local JSON source
- Displays player names and points in a table
- Calculates total and average points
- Highlights players above a score threshold
- Allows changing the highlight color
- Demonstrates React state and effect hooks

## Status

Completed educational project. It is no longer actively developed and is kept as part of my React learning history.
